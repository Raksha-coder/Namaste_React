😋JSX - JSX is Html like syntax (not exact HTML).
1.Facebook developer create JSX to make the react element syntax simpler .
2.we can write react without JSX using React.createElement
3.JSX and react are different
4.JSX is where we merge HTML and Javascript Together rather than creating separate files for both.
5.JSX is not a pure javascript.
6.Browser does not know JSX, so it is get converted to React first using parcel so that browser will understand this.

Note : React Element and JSX are one and the same thing.

😋JSX(transpiled before it reaches the JS Engine) - PARCEL
1.Using Babel parcel transpile JSX code into REACT.
2.Babel is a normal js package.
3.Babel is not created by Facebook.

JSX => React Element(transpile using Babel) => object => HtmlElement.

😋Difference between normal html,js and JSX
1.in JSX we use className an in html we use className
2.we use camelCase in JSX for attribute and in html we use all small case .
Example : tabIndex=""  and tabindex=""
